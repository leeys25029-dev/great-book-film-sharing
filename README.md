# great-book-film-sharing
我会在这里记录一些我看过的觉得还不错的书和电影，附上简单的评价，希望你也会喜欢
## Book
【我是寨子里长大的女孩】：虽然对于作者描述的一些细节让人觉得耸人听闻，整体来说很真诚，一个山寨里长大的孩子的成长故事。作者的身体和心理的疾病也都或多或少来自童年的经历，在经历了这么多苦难后，她还是在外人看来一个充满活力的人。看到鲁豫老师的访谈里，作者现在正在美国攻读社区大学，被作者的乐观和活力有些感染了。

【清醒地活】：《臣服实验》的作者，提了一个概念还是很有启发的，把你脑海里的声音认作一个神经质的室友，观察这个声音到底是不是你自己的。站在一个第三人称的角度去观察脑海里的想法和思绪，书里具体的方法论不如《臣服实验》，更多是一些概念的描述。

【哈撒比斯：谷歌AI之脑】：不单单是在讲哈萨比斯的故事，后半段几乎把从Alphago到25年DeepSeek横空出世，中间的AI圈大事件涵盖了。书里也有一些细节的记录，从中还是学习到不少东西。

⭐️【切尔诺贝利的祭祷】：诺贝尔文学奖获得者阿列克谢耶维奇的作品，书里记录了经历过或生活在切尔诺贝利的人们的声音。书里有些描写让人觉得很不适，比起HBO拍的迷你剧要更让人毛骨悚然，推荐阅读。

【智能简史】：从生物的进化和学习的角度，讲了一些神经元和学习相关的内容，生物的特性特性直接启发了很多算法。作为科普向阅读还是不错的，书的后部分设计的生物部分太多，算法的部分结合的太少。
